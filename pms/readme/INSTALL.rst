This module depends on modules including ``base``, ``mail``, ``sale``,
``multi_pms_properties``, ``web_timeline`` and ``web_responsive``.
Ensure yourself to have all them in your addons list.

When upgrading to version 16.0.5.1.0, restart Odoo and upgrade ``pms`` to
create and populate the stored assigned room types field and load the
updated views. Reload the browser to load the updated backend assets.
