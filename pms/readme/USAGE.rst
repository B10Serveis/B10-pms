Reservation timeline
~~~~~~~~~~~~~~~~~~~~

Open the reservations action and select the timeline view. The left-hand
search panel provides filters for property, reservation status, payment
status, assigned room type and pricelist. The same panel remains available
in the list and kanban views.

The **Not cancelled** filter is enabled by default for the reservations
action. Remove it to include cancelled reservations, then select the desired
status in the search panel. Opening **Cancelled Rooms** from a folio still
shows its cancelled reservations directly.

The **Room Type** filter in the panel uses the rooms actually assigned to
the reservation nights, rather than the room type sold on the reservation.
You can select several types. A reservation that changes rooms during its
stay matches each of its assigned room types. Reservations without an
assigned room do not match a selected assigned room type. The room type
search field in the top search bar continues to refer to the type sold.

Timeline bars use the following colours, also shown in the legend:

* Grey: pre-reservation.
* Blue: pending arrival.
* Green: on board.
* Purple: out.
* Red: cancelled, when included by the filters.
* Orange: arrival delayed.
* Yellow: departure delayed.

These colours describe the reservation status. Room cleaning and maintenance
status are managed separately. The status label is **Estat** in Catalan and
**Estado** in Spanish.
